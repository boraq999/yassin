## ✨ المميزات

- 📱 **متوافق مع جميع الأجهزة** (كمبيوتر، تابلت، موبايل)
- 🌍 **11 عملة مختلفة** يمكن الاختيار بينها
- 🔄 **تحديث فوري** عند تغيير العملة
- 🎨 **تصميم عصري وأنيق** مع تأثيرات حركية
- 🔒 **نظام بروكسيات متعددة** لضمان العمل على جميع الأجهزة
- ⚡ **سريع وخفيف** - لا يحتاج لأي مكتبات خارجية

## 🚀 كيفية الاستخدام

### الطريقة الأولى: GitHub Pages (موصى بها)

1. ارفع الملفات على GitHub
2. فعّل GitHub Pages من إعدادات المستودع
3. افتح الرابط من أي جهاز

### الطريقة الثانية: محلياً

1. افتح الملف `index.html` باستخدام Live Server في VS Code
2. أو استخدم أي خادم محلي آخر

⚠️ **ملاحظة مهمة**: لا تفتح الملف مباشرة من المتصفح (file:///) لأن البروكسيات لن تعمل.

## 🔧 كيف يعمل؟

1. **جلب البيانات**: يتصل الموقع بصفحة أسعار العملات في موقع المصرف المركزي
2. **البروكسيات**: يستخدم نظام بروكسيات متعددة للتغلب على قيود CORS
3. **التحليل**: يستخرج البيانات من جدول HTML
4. **العرض**: يعرض الأسعار بشكل جميل ومنظم

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3 (مع Animations)
- Vanilla JavaScript (ES6+)
- Fetch API
- DOMParser API

## 🔄 نظام البروكسيات

الموقع يستخدم 4 بروكسيات مختلفة بنظام Fallback:

1. **AllOrigins** - يعمل بشكل ممتاز على الموبايل
2. **CORS Anywhere** - بديل قوي
3. **CodeTabs** - سريع على الكمبيوتر
4. **ThingProxy** - احتياطي

إذا فشل أحدهم، يجرب التالي تلقائياً حتى ينجح.

## 🐛 حل المشاكل

### المشكلة: "فشل الجلب" على الموبايل
**الحل**: تم حلها! الكود الجديد يجرب 4 بروكسيات مختلفة

### المشكلة: البيانات لا تظهر
**الحل**: تأكد من فتح الصفحة عبر خادم (Live Server) وليس ملف محلي

### المشكلة: بطء في التحميل
**الحل**: الكود يحتوي على Timeout (10 ثواني) لكل بروكسي
